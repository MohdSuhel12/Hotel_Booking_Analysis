 Hotel Booking Cancellation Analysis

📊 Project Overview
This is a comprehensive data analytics project that analyzes hotel booking patterns to understand cancellation behavior, identify revenue opportunities, and provide actionable business insights. The project demonstrates end-to-end data analytics skills including data cleaning, exploratory data analysis, and interactive dashboard creation.

 📈 Dataset
Source: Kaggle - Hotel Booking Demand  
Records: 119,390 bookings  
Columns: 32 features  
File: `data/hotel_bookings.csv`

 Key Features
- Hotel type (Resort/City)
- Booking details (dates, lead time, length of stay)
- Guest information (adults, children, country)
- Booking attributes (market segment, deposit type, customer type)
- Rating and review scores
- Revenue metrics (ADR - Average Daily Rate)

🛠️ Tools & Technologies
- Python - Data processing and analysis
- Pandas - Data manipulation
- Matplotlib & Seaborn - Data visualization
- Jupyter Notebook - Development environment
- Power BI - Interactive dashboard
- SQL - Data querying
